# Portefólio Pessoal — Guilherme Fernandes

Bem-vindo ao repositório do meu portefólio pessoal!

Este projeto consiste no desenvolvimento do meu website pessoal, criado com o objetivo de apresentar o meu percurso académico e profissional, dar a conhecer os projetos em que tenho trabalhado e divulgar o meu trabalho na área do desenvolvimento web.

O website funciona também como uma plataforma de apresentação profissional, contacto e divulgação de possíveis serviços freelance.

**Website:** https://guilhermefernandes.hstn.me/

## Sobre o projeto

O portefólio foi desenvolvido de raiz, com especial atenção ao design, à organização dos conteúdos, à experiência de utilização e à adaptação a diferentes dispositivos.

### Funcionalidades

- Apresentação pessoal e profissional.
- Percurso académico e experiência profissional.
- Galeria de projetos com páginas individuais.
- Imagens e detalhes dos projetos desenvolvidos.
- Formulário de contacto funcional.
- Envio de mensagens através de SMTP.
- Página de Política de Privacidade.
- Design responsivo para computadores, tablets e telemóveis.

## Tecnologias utilizadas

- **PHP** — Desenvolvimento da lógica do servidor e conteúdos dinâmicos.
- **HTML5** — Estrutura das páginas.
- **CSS3** — Estilização e adaptação a diferentes dispositivos.
- **JavaScript** — Interatividade e funcionalidades do website.
- **PHPMailer** — Envio de mensagens através do formulário de contacto.
- **MySQL** — Tecnologia de bases de dados utilizada noutros projetos apresentados no portefólio.
